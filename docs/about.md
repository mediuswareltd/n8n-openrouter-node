# About n8n OpenRouter Node

## Who maintains it

n8n OpenRouter Node is built and maintained by [Mediusware](https://mediusware.com), a software company that designs and ships products for clients worldwide. The source lives at [github.com/mediuswareltd/n8n-openrouter-node](https://github.com/mediuswareltd/n8n-openrouter-node).

## Why it exists

An n8n community node for sending prompts to OpenRouter models including GPT-4o, Claude, Gemini, Llama, and more.

We publish these tools so teams can evaluate the real software, not a slide deck: clone it, run it, and read how it is put together.
