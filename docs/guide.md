# Guide

## What it is

An n8n community node for sending prompts to OpenRouter models including GPT-4o, Claude, Gemini, Llama, and more.

## Stack

`n8n`, `TypeScript`, `OpenRouter`

## Capabilities

### OpenRouter access

One credential for many frontier models.

### n8n community node

Install from Settings → Community Nodes.

### Prompt completions

Send prompts and return model output in workflows.

### Self-host friendly

Also installable via npm on self-hosted n8n.
